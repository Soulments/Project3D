# 플레이 영상 구성안

직접 촬영·편집용 구성안이다 (영상은 이 환경에서 만들 수 없어 구성만 정리). 목표 길이 2분 내외, 자막은 영어/한글 병기를 권장한다.
화면 녹화는 에디터가 아니라 **빌드(Windows)** 로 하는 편이 프레임이 안정적이고 에디터 UI가 안 보인다.

| 구간 | 시간 | 화면 | 자막 / 설명 |
| --- | --- | --- | --- |
| 1. 타이틀 | 0:00–0:08 | 타이틀 → START | "타이틀 → 던전 → 결과, 한 판 루프" |
| 2. 이동·공격 | 0:08–0:25 | 던전 진입, 이동·점프, 기본공격, 히트스탑·카메라 쉐이크 | "히트스탑 + Impulse 쉐이크 (이벤트로 연결)" |
| 3. 적 선딜 | 0:25–0:50 | 근접 적의 붉은 선딜 → **물러서서 회피** → 반격, 원거리 적의 투사체 | "선딜 중 물러나면 빗나감 — 타격 순간에 다시 판정" |
| 4. 행동 교체 | 0:50–1:00 | (선택) 에디터에서 근접 적 SO를 원거리 SO로 바꿔 동작이 바뀌는 장면 | "SO만 바꿔 행동 교체, 코드 수정 없음" |
| 5. 보스 1페이즈 | 1:00–1:25 | 슬래시 연타 회피 | "패턴 체이닝 (UniTask)" |
| 6. 페이즈 전환 | 1:25–1:40 | HP 50% 이하 → 히트스탑 + 큰 쉐이크, 충격파 바닥 범위 원 | "페이즈 전환 연출은 EventBus 이벤트 하나로" |
| 7. 결과 | 1:40–1:55 | 보스 처치 → VICTORY (시간 · 처치 수 · 사망) → BACK TO TITLE | "결과는 GameSession으로 씬 사이 전달" |
| 8. 측정 | 1:55–2:10 | 슬라이드: 드로우콜 1,433 → 408, Object Pool CPU −90%, QuadTree 미채택 | "추측 말고 측정으로 결정" |

촬영 팁
- 보스는 HP가 400이라 기본공격(15)으로 27회 정도가 필요하다. 시연용으로는 `Boss_Stat`의 maxHP를 낮춰 두면 편하다 (촬영 후 되돌릴 것).
- 영상에 실기기 장면이 없다면 "모바일 컨트롤은 에디터에서 검증"이라고 밝히는 편이 안전하다.
- 모바일 화면을 넣으려면 `MobileControlsUI`의 `_forceShow`를 켜고 가로 화면으로 녹화한다.
